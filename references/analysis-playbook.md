# 分析手册：怎么给评价、怎么不做错

报告里最容易被写坏的是"评价"部分。数据是工具给的，判断是自己的，这一份文件负责后者。

---

## 一、四维评分锚点（0–5 分，可打半分）

### 成长性 `growth`
看增速水平 + 稳定性 + 可持续性，三者任一塌了都上不了 4 分。

| 分数 | 特征 |
|---|---|
| 5 | 三年营收 CAGR > 25%，且无单年负增长 |
| 4 | CAGR 15–25%，增速波动小于 10pct |
| 3 | CAGR 5–15%，或增速明显放缓但仍为正 |
| 2 | CAGR 0–5%，或已出现单年负增长 |
| 1 | 营收连续下滑，或最新年度跌幅 > 20% |
| 0 | 营收腰斩，或数据无法确认 |

### 盈利能力 `profitability`
ROE 绝对值优先，其次看趋势，再看毛利率是否被侵蚀。

| 分数 | 特征 |
|---|---|
| 5 | ROE > 25% 且三年未降超 3pct，毛利率稳定 |
| 4 | ROE 15–25%，毛利率波动小于 2pct |
| 3 | ROE 10–15%，或 ROE 高但在下滑 |
| 2 | ROE 5–10%，毛利率同步走低 |
| 1 | ROE < 5%，或毛利率大幅下滑 |
| 0 | 亏损 / ROE 为负 |

### 收入结构 `segment`
看集中度是否健康、结构在升级还是降级。

| 分数 | 特征 |
|---|---|
| 5 | 主力产品占比稳定且毛利高，第二曲线已成形（占比 > 15% 且增长） |
| 4 | 结构稳定，第二曲线尚在培育 |
| 3 | 结构基本稳定，但副业占比在缓慢抬升 |
| 2 | 主力占比连续下滑超 5pct，或副业占比快速抬升 |
| 1 | 主力产品失速，收入靠低毛利业务撑 |
| 0 | 主营实质上已经替换，原有逻辑不成立 |

### 估值性价比 `valuation`
**必须与增速配对看**，单看分位数一定错。

| 分数 | 特征 |
|---|---|
| 5 | PE 分位 < 30% 且增速为正，或 PEG < 1 |
| 4 | 分位 30–50% 且增速稳，或分位偏高但增速能消化 |
| 3 | 分位 50–70%，增速与估值大致匹配 |
| 2 | 分位 > 70% 且增速放缓；或分位低但利润在下滑 |
| 1 | 分位 > 85% 且利润负增长（分母塌陷） |
| 0 | 估值失去意义（亏损、净资产为负） |

## 二、四种必须点破的错配

这四种情况在报告里出现时，评价段必须明确指出，否则等于没写。

1. **增收不增利**：营收正增长、净利负增长 → 成本端或费用端出了问题，看毛利率有没有同步下滑。若毛利率没降，是费用或减值，去看销售费用率。
2. **增利不增收**：营收负增长、净利正增长 → 通常来自降本、投资收益或一次性损益，可持续性弱，要标注"质量存疑"。
3. **PE 高分位 + 利润腰斩**：分母（盈利）塌了导致 PE 被动抬升，**不能读作估值变贵**。此时 PB 更有参考意义，且要提示"PE 分位失效"。
4. **PE 低分位 + 利润下滑**：典型价值陷阱形态。便宜是因为市场在提前定价更差的报表，不是机会。

## 三、行业特例

- **银行**：无毛利率，看 ROE、净息差、不良率；收入构成用"利息净收入 / 手续费及佣金 / 其他"；PB 比 PE 更重要，PE 分位参考价值低。
- **保险**：利润受投资收益与准备金假设影响大，单年波动不代表经营变化；看新业务价值（若可得），否则用营收增速 + ROE 组合，并在正文注明利润波动原因可能非经营性。
- **券商**：强周期，营收与市场成交量高度相关；"近三年"可能横跨牛熊，必须指出周期位置，否则增速对比无意义。
- **周期股（钢铁、煤炭、化工、航运）**：低 PE 常出现在景气顶点，高 PE 出现在底部，**PE 分位方向相反**。此时应以 PB 和产品价差为主，且明确写"周期股 PE 分位不适用"。
- **地产 / 建筑**：关注预收款（合同负债）与现金流，营收确认滞后，单看利润表会误判。
- **次新股**：不足三年数据，`periods` 缩短，成长性评分要标注"样本期过短"。

## 四、文案范式

**结论标题**（`verdict.title`）——要有立场，可直接当标题用：

- ✅ "茅台增速换挡但底盘极稳；五粮液营收腰斩，PE 高分位是分母塌陷不是变贵"
- ✅ "两家都是 20% 增速的白马，差别在收入结构：一家靠主品提价，一家靠副业铺量"
- ❌ "两家公司各有优劣，需结合自身情况判断"（等于没说）
- ❌ "A 公司营收更高，B 公司增速更快"（复述数据，没有判断）

**段落**——每段一个论点，先结论后数字：

- ✅ "毛利率只降 0.75pct，说明这轮下滑是量的收缩而非价的下杀，定价权没丢。"
- ❌ "2025 年毛利率为 91.18%，2024 年为 91.93%，2023 年为 91.96%。"（这是表格的活，不要写进正文）

**亮点 / 风险**——每条必须带数字，且是**这一家公司特有**的：

- ✅ "PE 20.4 倍处于近三年 37.8% 分位，估值已完成一轮出清"
- ❌ "公司经营稳健，品牌力强"（无信息量）

**情景建议**（`scenarios`，仅对比模式）——按"关注点 → 选谁 → 为什么"三段式，覆盖 2–3 种典型诉求（确定性、弹性、避险），让读者自己代入：

- "要的是确定性现金流与分红 → A → 毛利率 91% 稳定、ROE 34%、PE 分位 37.8%"
- "博弈业绩反转弹性 → B → PB 仅 8.1% 分位，但需先确认数据口径，风险显著更高"

## 五、交付前问自己三个问题

1. 如果只让读者看标题那一句话，他知道该选谁、或者该警惕什么吗？
2. 报告里每一个形容词，都能在图表数字上找到依据吗？
3. 有没有把"数据异常"当成"经营结论"来写？（最典型的错误：把待复核的暴跌直接解释成战略失败）
